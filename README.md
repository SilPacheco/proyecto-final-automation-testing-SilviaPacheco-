PROYECTO DE AUTOMATIZACON QA - Saucedemo
El presente proyecto contiene pruebas automatizadas en Python, realizadas sobre la web  demo www.saucedemo.com, especialmente diseñada para prácticas de testing.

Las pruebas automatizadas se realizaron sobre: 
*Login exitoso
*Visualización del catálogo de productos
*Agregar un producto al carrito y validarlo

El proyecto aplicó automatización mediante Selenium, utilización de Pytest y marcadores, esperas explícitas y buenas prácticas para estructurar las pruebas.

Tecnologías utilizadas:
Python 3.11
Selenium WebDriver
Pytest
Webdriver-manager, para buscar el Chrome Driver automáticamente
Visual Studio Code, como entorno de desarrollo

Instrucciones para clonar el repositorio:
1-git clone https://github.com/SilPacheco/pre-entrega-automation-testing-Silvia-Pacheco.git
2-ingresar al proyecto
3-Instalar dependencias mediante pip install -r requeriments.txt.
